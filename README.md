# Atividade de Requisitos

## Projeto

Este repositório apresenta a atividade prática de Engenharia de Requisitos, utilizando como contexto um sistema de agendamento de consultas.

O objetivo é representar os requisitos identificados por meio de diferentes artefatos de especificação.

## Artefatos desenvolvidos

### 1. Histórias de Usuário

As histórias de usuário representam as necessidades do paciente e descrevem as principais funcionalidades esperadas do sistema.

- Agendar consulta
- Consultar agendamentos
- Cancelar consulta

### 2. Critérios de Aceitação

Os critérios de aceitação definem as condições que devem ser atendidas para considerar cada história de usuário implementada corretamente.

### 3. Casos de Uso

Os casos de uso detalham a interação entre o paciente e o sistema para realizar as principais funcionalidades.

## Uso da Inteligência Artificial Generativa

A Inteligência Artificial Generativa foi utilizada como apoio durante a análise e especificação dos requisitos.

A IA auxiliou na identificação e organização dos requisitos, na elaboração das histórias de usuário, na definição dos critérios de aceitação e na estruturação dos casos de uso.

As sugestões fornecidas pela IA foram analisadas e adaptadas de acordo com o contexto do projeto. Algumas sugestões foram aproveitadas, outras foram modificadas para adequação ao sistema e aquelas que não estavam relacionadas ao escopo foram descartadas.

## Estrutura do repositório

- `historias-usuario.md` — histórias de usuário do sistema.
- `criterios-aceitacao.md` — critérios de aceitação das funcionalidades.
- `casos-de-uso.md` — casos de uso e fluxos de interação.
