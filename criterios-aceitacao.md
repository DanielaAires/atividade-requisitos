# Critérios de Aceitação

## História 1 - Agendar consulta

- O sistema deve permitir que o paciente visualize os horários disponíveis.
- O paciente deve conseguir selecionar uma data e um horário.
- O sistema deve confirmar o agendamento após a seleção do horário.
- O sistema não deve permitir o agendamento de um horário já ocupado.

## História 2 - Consultar agendamentos

- O sistema deve permitir que o paciente visualize suas consultas.
- Cada consulta deve apresentar a data e o horário.
- O paciente deve conseguir identificar quais consultas estão agendadas.

## História 3 - Cancelar consulta

- O sistema deve permitir que o paciente selecione uma consulta agendada.
- O sistema deve solicitar a confirmação do cancelamento.
- Após o cancelamento, o horário deve ficar disponível novamente.
- O sistema deve informar que o cancelamento foi realizado com sucesso.
