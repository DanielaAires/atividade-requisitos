# Histórias de Usuário

## História 1 - Agendar consulta

**Como** paciente,  
**quero** agendar uma consulta,  
**para** escolher um horário disponível para meu atendimento.

## História 2 - Consultar agendamentos

**Como** paciente,  
**quero** visualizar minhas consultas agendadas,  
**para** saber a data e o horário do meu atendimento.

## História 3 - Cancelar consulta

**Como** paciente,  
**quero** cancelar uma consulta,  
**para** liberar o horário caso eu não possa comparecer.
